# AI Video Director - Highfield/Fable Reverse Engineering Pipeline

Purpose:
Build an AI system that analyzes luxury reference videos and generates new branded videos using your own furniture/products.

Core pipeline:

Reference Video
 -> yt-dlp / Upload
 -> FFmpeg
 -> PySceneDetect
 -> Vision AI Analysis
 -> LangGraph Agent System
 -> Prompt Generation
 -> Kling / Runway / Wan / Hunyuan
 -> Final Video

This package is a technical handoff blueprint.
